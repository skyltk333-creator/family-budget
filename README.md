# 우리집 가계부 (첫 번째 MVP)

신한카드 / 토스뱅크 XLSX 거래내역을 브라우저에서만 분석하는 정적 웹사이트입니다.

## 실행
1. GitHub Codespaces에서 프로젝트 폴더를 엽니다.
2. `python3 -m http.server 8000` 실행
3. Codespaces의 포트 8000을 브라우저에서 엽니다.
4. `가상 데이터 체험` 버튼으로 먼저 테스트합니다.
5. 하나의 파일 선택란에서 신한카드/토스뱅크 `.xlsx` 파일을 함께 선택하고 `파일 분석하기`를 누릅니다. 파일 내용으로 금융기관을 자동 판별하며, 파일별 판별 결과를 표시합니다. 파일당 최대 15MB입니다.
6. 지원하지 않는 파일이나 분석 가능한 거래가 없는 파일이 있으면 파일명과 오류를 안내하고 선택한 파일 전체를 반영하지 않습니다. 기존 분석 결과는 유지됩니다.

## Cloudflare Pages 배포
- GitHub 저장소에 `index.html`, `style.css`, `app.js`를 업로드합니다.
- Cloudflare Dashboard → Workers & Pages → Create → Pages → Connect to Git.
- Framework preset: None / Build command: 비워둠 / Build output directory: `/` (저장소 루트에 파일을 둔 경우).
- 공개 저장소에 실제 거래내역 엑셀이나 CSV를 절대 커밋하지 마세요.

## 주요 기능
- 여러 XLSX 파일 일괄 선택 및 헤더 기반 신한카드·토스뱅크 자동 판별
- 두 금융기관의 서로 다른 헤더 위치 자동 인식
- XLSX 파일 브라우저 내부 분석 (네트워크 전송 없음)
- 카드 취소상태 제외, 통장 입금 제외, 카드대금 중복 후보 제외
- 거래처 키워드 기반 카테고리 자동 분류 및 수정
- 월별 소비 현황, 카테고리별 합계, 월별 추이
- 월별 CSV 다운로드

## 제한 사항 및 주의
- 최신 Chrome/Edge 등 `DecompressionStream('deflate-raw')` 지원 브라우저 권장.
- 첫 번째 워크시트의 일반적인 XLSX 파일만 지원하며, 일부 암호화/특수 형식은 지원하지 않습니다.
- 카드 취소 원거래 매칭, 카드대금과 카드 사용내역 정밀 대조는 아직 미구현입니다. 취소상태 표시 거래와 카드대금으로 추정되는 출금만 제외합니다.
- 같은 거래처명 분류를 바꾸면 동일 출처·거래처의 다른 거래에도 적용됩니다. 금융기관·거래처명·분류·마지막 수정 시각을 현재 브라우저의 localStorage에 저장하고, 다음 파일 분석에도 적용합니다. 거래내역 전체는 저장하거나 전송하지 않습니다.
- 분류 수정 일시는 기기 현지 시간으로 표시합니다. 수정 시각 오름차순·내림차순 정렬과 선택 월의 최근 수정 보기, CSV 수정 일시 열을 제공합니다. 개별 거래 변경 이력 전체를 보관하는 기능은 아닙니다.
- 분석 데이터 초기화는 저장된 규칙을 삭제하지 않습니다. 다른 기기·브라우저와는 동기화되지 않으며 사이트 데이터 삭제 시 규칙도 삭제됩니다. 공용 브라우저에서는 규칙이 공유됩니다.
- 가상 데이터 체험에서 바꾼 분류는 저장하지 않습니다. 저장이 차단되거나 실패하면 화면에 안내하며 현재 분석 중에만 적용합니다.
- 거래내역 전체는 브라우저 메모리에만 보관하며 새로고침 시 사라집니다.
- 은행 입출금의 일반 계좌이체는 실제 지출일 수 있으므로 자동 제외하지 않고 검토 대상으로 둡니다.
- 분류 결과는 참고용입니다. 개인 금융정보가 포함된 원본 파일은 GitHub에 업로드하지 마세요.

## 검증
- `node --check app.js`: JavaScript 문법 검사.
- `node tests/rules.test.cjs`: 합성 데이터로 규칙 저장·복원, 실제 분석 경로의 규칙 적용, 수정 시각 정렬, CSV, 저장 실패, 체험 데이터 분리를 검증합니다.
